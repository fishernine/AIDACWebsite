# AIDAC 联系信息系统指南

## 📋 系统概述

AIDAC 联系信息系统是一个完整的信息收集和管理解决方案，用于处理网站访客提交的联系表单信息。系统提供用户友好的表单界面和强大的管理功能。

## 🎯 主要功能

### 1. 联系表单
- **用户友好界面**: 美观的表单设计，易于填写
- **完整信息收集**: 姓名、邮箱、电话、组织、职位、主题、消息等
- **表单验证**: 实时验证必填字段和格式
- **订阅选项**: 用户可选择订阅新闻通讯
- **成功反馈**: 提交后显示确认消息

### 2. 信息管理
- **本地存储**: 使用浏览器本地存储保存数据
- **状态管理**: 新消息、已查看、已回复三种状态
- **搜索筛选**: 按状态、主题、关键词筛选
- **数据导出**: 支持JSON格式导出所有数据

### 3. 管理界面
- **统一管理**: 在统一管理系统中查看所有提交
- **独立管理**: 专门的联系管理页面
- **实时更新**: 数据实时同步显示
- **批量操作**: 支持批量状态更新和删除

## 🚀 使用方法

## 📊 表单字段说明

### 必填字段
- **First Name**: 用户名字
- **Last Name**: 用户姓氏
- **Email**: 邮箱地址（自动验证格式）
- **Subject**: 主题（下拉选择）
- **Message**: 消息内容（最少10个字符）

### 可选字段
- **Phone**: 电话号码
- **Organization**: 组织/机构名称
- **Position**: 职位/头衔
- **Newsletter**: 新闻通讯订阅选项

### 主题选项
- General Inquiry（一般咨询）
- Research Collaboration（研究合作）
- Student Inquiry（学生咨询）
- Partnership Opportunity（合作机会）
- Technical Support（技术支持）
- Other（其他）

## 🔧 管理功能

### 状态管理
- **New**: 新提交的消息
- **Reviewed**: 已查看的消息
- **Replied**: 已回复的消息

### 筛选功能
- **状态筛选**: 按消息状态筛选
- **主题筛选**: 按主题类型筛选
- **关键词搜索**: 搜索姓名、邮箱、消息内容

### 操作功能
- **查看详情**: 显示完整的联系信息
- **状态更新**: 标记为已查看或已回复
- **删除消息**: 删除不需要的消息
- **数据导出**: 导出所有联系数据

## 📈 统计信息

系统提供以下统计信息：
- **总提交数**: 所有联系表单提交的总数
- **新消息数**: 状态为"新"的消息数量
- **已查看数**: 状态为"已查看"的消息数量
- **已回复数**: 状态为"已回复"的消息数量
- **订阅者数**: 选择订阅新闻通讯的用户数量

## 🛠️ 技术特性

### 数据存储
- **本地存储**: 使用localStorage存储数据
- **数据持久化**: 浏览器关闭后数据仍然保存
- **数据备份**: 支持导出JSON格式备份

### 表单验证
- **实时验证**: 输入时实时验证格式
- **必填检查**: 确保必填字段不为空
- **邮箱验证**: 验证邮箱格式正确性
- **长度检查**: 确保消息内容足够详细

### 用户体验
- **响应式设计**: 适配各种设备屏幕
- **友好提示**: 清晰的错误和成功消息
- **自动隐藏**: 消息提示自动消失
- **表单重置**: 提交后自动清空表单

## 📱 移动端支持

- **触摸友好**: 按钮和输入框适合触摸操作
- **自适应布局**: 在小屏幕上自动调整布局
- **键盘优化**: 移动端键盘输入优化

## 🔒 数据安全

- **客户端存储**: 数据存储在用户浏览器中
- **无服务器依赖**: 不需要后端服务器
- **隐私保护**: 不向第三方传输数据
- **本地处理**: 所有数据处理都在本地完成

## 🐛 故障排除

### 常见问题
1. **表单不提交**: 检查必填字段是否完整
2. **数据不显示**: 刷新页面或清除浏览器缓存
3. **验证失败**: 检查邮箱格式和消息长度
4. **功能异常**: 查看浏览器控制台错误信息

### 解决方案
1. **清除缓存**: 清除浏览器缓存和本地存储
2. **检查JavaScript**: 确保JavaScript已启用
3. **更新浏览器**: 使用最新版本的浏览器
4. **检查网络**: 确保网络连接正常
